# Roadmap

## Needed by about Q2 2027
- **Engine v4 — rolling anchor.** Today the model starts in Q4 2026 and weekly data re-anchor that quarter. When 2027 data arrive, the anchor quarter must move forward: extend history with each reported quarter, recalibrate on the new last quarter, and keep the scenario paths continuous.
- **Scenario tracker.** Compare post-anchor observations (capex filings, power prices, token prices, open-weight lag) with each scenario's path and show which scenario reality is tracking.

## Next
- Census data-centre construction from the monthly spreadsheet (today via AI research and review).
- Dashboard texts in German, French and Polish (the newsletter already is).
- Release webhooks for partners; a newsletter archive page.
- A Web Worker for the engine so custom scenarios never block the page.
- Accessibility audit (screen readers for the canvas charts: table views exist for the matrix and ledger).
- Zenodo DOI for each weekly release.
