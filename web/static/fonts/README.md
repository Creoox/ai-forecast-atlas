# Bundled fonts

Archivo and Martian Mono are served locally. Visitors do not contact Google Fonts.
Both unmodified variable font files are under the SIL Open Font License 1.1;
their licence notices are included beside them and copied into the built website.

Downloaded on 19 October 2026 from the official Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/archivo
- https://github.com/google/fonts/tree/main/ofl/martianmono

The build adds a content hash to each served filename and embeds the same files
in the standalone preview. Keep the original names here so the build is repeatable.
