## 1.1.0 — 17 October 2026
- **AI research panel:** every daily research question goes to five AI agents — OpenAI, Anthropic Claude, Google Gemini, xAI Grok and DeepSeek. Each answer brings its source page and quote, or is marked as the model's own knowledge. Answers are combined by **weighted median** with weights the editor sets (0–10; knowledge answers count half by default); the published value is one agent's real answer with its own source, and every agent's answer is kept with the value (`via.panel`) and shown on the dashboard, release pages, newsletters and MCP. Reviewers see all answers side by side and can publish another agent's answer ("Use this answer"). The second-opinion role of 1.0 is replaced by the panel.
- **X watch:** Grok scans X every weekday with its `x_search` tool for posts that matter to the monitor — from credible accounts (official, executives, journalists and media, analysts, researchers) and from accounts with heavy impact on X — and labels credibility and impact. The editor approves each item; approved items appear in a new dashboard panel, the weekly release (`xwatch`), feeds, the newsletter ("X watch"), `data/xwatch.json`, the MCP tool `get_xwatch`, and the assistant can cite them as [X12]. Signals, not data: they never change the model.
- **Admin:** new "AI agents" tab (keys, models, weights, tasks, status and spend per agent, how answers are combined, X watch settings, assistant and writer), new "X watch" tab (review, approve, withdraw, "Scan X now"), review cards with every agent's answer.
- **Providers, checked against the current API documentation:** Claude research runs as message batches (half price), OpenAI in background mode; xAI requests without inline citation markers and with the exact cost reported; Gemini's redirect links are matched by domain and never published; DeepSeek answers without slow "thinking" and is never used for the visitor chat (it processes data in China without a DPA).
- **Legal:** imprint and privacy notice for Creoox AG as a Liechtenstein company in the EEA (register FL-0002.524.394-4, Datenschutzstelle Liechtenstein; no EU representative needed); X watch and the research providers described in the privacy notice.
- Research budget default raised to $25 a month for all agents and X watch.
- `AGENTS.md`: layout, commands, hard constraints and review guidelines for AI coding agents and reviewers.
- Fixes from the Codex review of pull request #1: a finished Claude batch is kept when downloading its answer fails for a passing reason (timeout, network, 408, 429, 5xx) and is downloaded on a later run; the download becomes its own step when the run has too little time left, and every poll request ends before the run's deadline; the X scan is tried again when xAI is busy or unreachable; the cost reserved for a Claude batch keeps web searches at full price, as the settlement does; X watch logs record decisions by id only, so a rejected post's text is gone with the rejected list after 45 days. Second round: a saved results address is checked against the provider's current address before every download (the key is never sent elsewhere), and a status or results answer cut off after "200" counts as a passing failure. Network failures are now marked as such ("network: …").
- Independent review fixes: agents without web access can only give AI knowledge (links they name are not used); Google redirect links never become sources; answers without a usable link count with the knowledge factor; impossible numbers (1e400) and `"found": "false"` are rejected, and a data file is never overwritten when encoding fails; agreement uses one band (tolerance × value, with a floor near zero); a value changed by the reviewer is no longer credited to the lead model, and the reviewer's note is shown; background mode falls back per provider and only when refused, busy providers are retried; the day's agents are fixed when the run starts; slow direct answers get a second try; "Run the daily data check now" resumes, restarting needs two clicks. X watch: the public list follows the keep period daily, confirming pages are checked against the search results, the editor can untick posts, pages and ledger links, the same post is never queued twice, the search window starts at the last scan (no weekend gap), up to 20 items per release and the whole month in the monthly newsletter, Withdraw also removes an item from published releases and feeds; privacy notice updated to match. The operator's details moved to `config/operator.json`.

## 1.0.0 — 17 October 2026
- Guidance and trust: guided tour, an explainer for every panel and tab, glossary, source cards behind every number (source, link, quote, references, how it entered the data, review date; formulas and inputs for model results), a "Sources & methods" view, cited and clickable sources in assistant answers, `assets/methods.json`, MCP tool `get_sources`.
- AI knowledge as a source: research agents and the assistant may contribute their own knowledge or observations without a citable page; such values carry the label “AI knowledge” with the model, date and explanation (status `ai-knowledge`), and assistant answers mark them with an [AI] chip.
- Provenance in the data: approvals require a source link (or the AI knowledge label); AI research must quote its source and keeps the pages its search returned; official-interface values record the exact endpoints; release pages and newsletters show the sources of every change.
- Hardening after an independent review: admin actions that change something need POST with the CSRF header and work only at the site's own address; resumable daily steps with OpenAI background mode for research; AI costs booked before each call; a cap on concurrent assistant answers; right-most client address behind the host proxy; staged releases and settings stored as guarded files; stricter chart filter; per-batch unsubscribe check, batch retries, intros written before sending, monthly edition = first send of the month, daily limit with a reserve for confirmations; automatic deletion periods from the privacy notice; update package keeps `.htaccess`.

- Public site for home.pl: static dashboard plus PHP endpoints, no database.
- Weekly release every Friday 13:00 Central European time; daily data check (SEC EDGAR, EIA, OpenRouter, Epoch AI, AI research with second opinion) and review queue.
- Release builder shared by the admin page and `tools/release.mjs`; deterministic files: JSON, CSV, SVG charts, data package; RSS, Atom, JSON Feed, iCalendar; MCP server; OpenAPI; llms.txt.
- Newsletter with Mailjet: double opt-in, topics, EN/DE/FR/PL, weekly or monthly, one-click unsubscribe, no tracking.
- AI assistant (OpenAI by default; Anthropic, Gemini, xAI, DeepSeek, Mistral, Perplexity, OpenRouter supported) with improvement suggestions inbox.
- Dashboard: light theme, layout customisation (expand, sizes, pin, move, hide, presets, reset to default), share, embed, data & API dialog, credits.
